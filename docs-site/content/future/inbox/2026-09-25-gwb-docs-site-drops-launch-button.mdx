`@godcreator/gwb-docs-site` 0.6.0 删掉了启动停止那一整块：`docs-site.list / start / stop / open / extend / running / view / unitSites / viewUnit`
九条命令、「站内预览」「站监控」两个窗格，以及登记到本插件单元树工具条上的「启动站点」按钮。站点插件现在只剩
`docs-site.create` 一条命令（人看站用 VS Code 扩展，agent 用站自己的 `pnpm dev`），不再注入 `gwbUnitFolder`，
也不再读出生证。理由见 gwb-docs-site 站的轨迹卡（2026-09-25 那两张）。

本仓要跟着改的地方：

- 说明书 `skills/unit-folder/SKILL.md` 第 91–100 行拿「启动站点」当 `registerToolbarButton` 的例子，命令名
  `docs-site.viewUnit` / `docs-site.unitSites` 已不存在；第 38 行「站用 `docs-site.create`」仍然成立
- 现状区 `docs/wiring.mdx`：描述、第 83、86、87 行的表格与「『启动站点』按钮：本插件这一侧」整节；
  `docs/service-and-commands.mdx` 第 49 行；`outputs/readme.mdx` 第 10 行
- `tests/toolbar.test.ts` 用 docs-site 的名字当测试数据，不影响正确性，改不改随意

另外值得判断一下：**工具条按钮登记口现在没有任何登记方了**。它原本只为这个按钮而设，按「只有一个使用者就写死、
没有使用者就删」的做法，可以考虑整个删掉（`registerToolbarButton`、`unit-folder.toolbarButtons`、浏览器侧的按钮渲染），
这会是本插件的破坏性版本；留着也行，但请在现状页写清楚它此刻没有使用者。

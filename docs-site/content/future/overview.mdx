# 这个件往哪去

`gwb-unit-folder` 管的是「单元」这个纯目录约定在工作台里长什么样：容器根下一层一个目录、
目录里一张 `unit.json` 出生证。它的长期方向一句话：**树上每一个动作推出来的事实，都值得
往外报**——点击推「人现在看的是哪个」，置顶推「人认定的工作现场」。报出去，别的件才有得
inject；本件自己对那些事实不做任何消费。

边界（正本在轨迹卡「单元文件夹」的「项目定义与边界」）：只管关于单元这个目录约定本身的
能力；为某个具体消费方发明的契约不进来。这条方向的一个自然推论写在
[刻意不做](/future/not-doing)：本件不认识任何消费方。

第二生产者的伏笔也在这条方向上：眼下「选中」只有树上一个来源；真出现第二个能「选中」
单元的件时，`current()` 那一格该从本件抽出、长成共享的「当前上下文」基础件——见
[路线图](/future/roadmap)。

# gwb-unit-folder

单元文件夹插件：现扫单元容器根读出生证、建单元、树里展开单元看文件、点文件在原文窗格看原文；
往外报「人现在看的是哪个单元」——服务 `ctx.gwbUnitFolder` 与事件 `unit-folder/selection`。本插件不认识任何消费方。

## 硬约束

- **服务、命令、出生证字段表是契约**：`gwbUnitFolder` 三个方法、事件载荷、十一条命令的名字与参数与回执、`unit.json` 的六项、
  设置键 `units-root`、data 文档 `pinned`、窗格 id `main` / `viewer`，改任何一样都是破坏性版本，先问人
- **带路径参数的命令共用同一道路径检查**：先现读设置 `units-root`，再把路径验成容器根内的绝对路径（词法与实际位置两道），
  越出根的一律回「路径不在容器根内」
- **配置与数据分开**：`units-root` 是设置（`gwbSettings.define`）；置顶是数据（`gwbData` 文档 `pinned`）
- **依赖单向**：判断与读盘（`scan` / `browse` / `current` / `create` / `vscode` / `toolbar`）不依赖 cordis；浏览器侧只经命令总线通信；
  本插件不 import 任何消费方
- **样式隔离靠类名前缀**：`src/client` 里每个类名都带 `unitfolder:`，本插件自己的类写成 `@utility`；漏写不报错，
  `pnpm check` 里由 `tests/prefix.test.ts` 查，`devkit.dev` / `devkit.release` 的样式检查再查一遍。外壳映射文件里没有的主题键
  （`leading-relaxed`、`animate-pulse` 这类）会编出写死的 fallback、过不了样式检查，写任意值或 `@utility`

## 怎么跑

仓是 pnpm workspace：仓根是不发布的 private 包，插件包在 `plugins/unit-folder/`。在仓根：

```powershell
pnpm check      # typecheck + lint + 纯逻辑测试
pnpm build      # esbuild（浏览器侧）+ tsc（node 侧）+ tailwindcss（样式表，类名前缀 unitfolder）
pnpm test:all   # 全量测试（含产物测试，要先 build）
```

在隔离 home 里验证：`devkit.dev {"home":"<home 名>","dir":"<仓根>","packages":["plugins/unit-folder"]}`；
发版：`devkit.release {"dir":"<仓根>","packages":["plugins/unit-folder"]}`，发到插件包 `publishConfig.registry` 写的团队源。

写插件、在隔离 home 里验证读 skill「gwb-devkit」，界面读「gwb-shell」，升版本号、发版读「gwb-release」，写文档读「docfirst-docs」。

## 文档

文档站在 `docs-site/`：`cd docs-site && pnpm doc` 检查；看站先 `pnpm build` 再 `pnpm start`（端口 4319），不用 dev 模式。从首页（`content/docs/index.mdx`，接缝图与接缝逐条）读起。
仓根 `README.md`、`CLAUDE.md`、这份 `AGENTS.md` 与随包说明书 `plugins/unit-folder/skills/unit-folder/SKILL.md` 都是生成物，
正本在 `docs-site/content/docs/outputs/`，改正本后在站目录运行 `pnpm doc:render`，生成物与正本放进同一个提交。
改了被钉的代码，同一个提交里在站目录 `pnpm doc:confirm` 写回、逐条复核剩下的黄灯（做法见 skill「docfirst-docs」）。

## 代码地图

路径相对插件包 `plugins/unit-folder/`：

- `src/index.ts` —— cordis 服务：窗格注册、十一条命令、服务、事件（先读它）
- `src/scan.ts` / `browse.ts` / `current.ts` / `create.ts` —— 出生证与现扫、路径验证与浏览、当前单元与置顶、建单元；不依赖 cordis，`tests/` 里直接测
- `src/client/` —— 浏览器侧：单元树窗格与原文窗格，只经命令总线通信
- `skills/unit-folder/` —— agent 说明书（生成物）

## @godcreator/gwb-unit-folder

### 提供

| 类别 | 名字 | 说明 |
| --- | --- | --- |
| 服务 | `gwbUnitFolder`：`current()` / `pinned()` / `registerToolbarButton(spec)` / `unitsRoot()` | 「人现在看的是哪个单元」与置顶单元；往单元树窗格的工具条登记按钮，回注销函数，登记方卸载时自动注销；容器根的绝对路径。形状见[服务与命令](/docs/service-and-commands#服务-ctxgwbunitfolder)。此刻注入它的只有 docfirst 插件 `@godcreator/gwb-docfirst-workflow`（局部注入，只调 `unitsRoot()`，建站时查端口） |
| cordis 事件 | `unit-folder/selection` | `current()` 变了就广播一次，载荷与 `current()` 同形（`UnitSelection`，变成没有时是 undefined） |
| 内核事件 | `{ t: 'gwb-unit-folder-toolbar' }` | 工具条按钮登记表一变就推一次，只给本插件自己的浏览器侧看，收到后重取 `unit-folder.toolbarButtons` |
| 命令 | `unit-folder.list` / `create` / `toolbarButtons` / `listDir` / `readFile` / `open` / `code` / `select` / `current` / `pin` / `unpin` | 十一条，参数与回执见[服务与命令](/docs/service-and-commands#命令) |
| 窗格 | `main`「单元」（工具窗格）、`viewer`「文件原文」（文档窗格） | 经 `gwbShell.registerPane` 注册 |
| 工具条按钮 | 登记表：别的插件经 `registerToolbarButton` 放进来的按钮 | 排在本插件自己的按钮后面；点击与「可不可用」都按登记里给的命令名调回登记方。此刻没有登记方 |
| 设置项 | `units-root` | 经 `gwbSettings.define` 声明，容器根的绝对路径 |
| data 文档 | `pinned` | 经 `gwbData` 存置顶表 `{ paths }` |
| 说明书 | `unit-folder` | 包根 `skills/unit-folder/`，经 `gwbSkills.register` 登记 |

### 注入

| 服务 | 提供方包 | 必需 / 局部注入 | peer 写法 | 用来做什么 | 缺了会怎样 |
| --- | --- | --- | --- | --- | --- |
| `gwbShell` | `@godcreator/gwb-shell` | 必需（`static inject`） | `^0.15.1` | 注册两个窗格、`describeSelf` 报名字 | 本插件不加载 |
| `gwbCommands` | `@godcreator/gwb-commands` | 必需（`static inject`） | `^0.6.0` | 登记十一条命令 | 本插件不加载 |
| `gwbSettings` | `@godcreator/gwb-settings` | 局部注入 | `^0.4.0`，可选 | 声明并读取 `units-root` | 照常加载；读不到容器根，命令一律回 `code: 'unconfigured'` |
| `gwbData` | `@godcreator/gwb-data` | 局部注入 | `^0.1.9`，可选 | 读写置顶文档 `pinned` | 照常加载；置顶只存在内存里，日志 warn 一次 |
| `gwbSkills` | `@godcreator/gwb-skills` | 局部注入 | `^0.4.7`，可选 | 登记说明书 `unit-folder` | 照常加载；agent 读不到这份说明书 |
| `gwbKernel` | 内核包 `@godcreator/gwb-kernel-desktop` | 不注入，`requireKernel(ctx)` 从根上下文取 | `^0.10.0` | 推工具条登记表变化的内核事件；接口类型也从内核包 `import type` | 宿主不是 gwb 内核时构造就抛错 |

peer 里还有 `cordis`（`^4.0.0-rc.10`）：本插件按值 import 它的 `Service` 基类。三个局部注入的插件在
`peerDependenciesMeta` 里标 `optional: true`——home 里可以没有它们，有的话版本要在范围里。
局部注入拿到的 `settings` / `data` 在那个插件卸载时设回 undefined。

### 按名字调用与约定通道

| 通道 | 对方 | 名字 | 用来做什么 |
| --- | --- | --- | --- |
| 命令总线（按名字调） | 登记工具条按钮的插件；此刻没有 | 登记里给的 `command` 与 `state` | 浏览器侧点按钮时调 `command`，参数 `{ unitPath?, item?, from, …args }`；画按钮前调 `state` 问可不可用与菜单项 |
| 内核事件（`gwbKernel.emit` → `window.gwb.on`） | 本插件自己的浏览器侧 | `gwb-unit-folder-toolbar` | 登记表变了，浏览器侧重取按钮表 |
| cordis 事件 | 注入 `gwbUnitFolder` 的消费方 | `unit-folder/selection` | 通知「当前单元」变了；此刻容器里没有插件订阅它 |
| 磁盘文件 | 人、agent | 每个单元目录下的 `unit.json` | 出生证：本插件建单元时写、扫描时读；人与 agent 手写或改写 |

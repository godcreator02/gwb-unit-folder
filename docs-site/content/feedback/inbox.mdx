## 2026-09-19 要追 shell 0.10：开窗格的行为变了，peer 会出范围

来源：gwb-ui-plugins（窗格模型第二版第一期，那边的 spec `pane-model-v2`；shell 0.10.0 今天发团队源）。

shell 0.10.0 按 gwb-release 抬了次版本号。插件调用面只增不减：桥上的 `openPane` 多一个可选的 `placement`，
跨插件的 `shell.openPane` 多收 `from`（来源窗格的实例 id）与 `placement`。但开窗格的**行为**变了，本仓 peer 的
`^0.9.1` 装上它会出 peer 警告：

- **本桌优先，打开从来不切桌面**：同一内容在别的桌面开着不再跳过去，就在本桌再开一份
- **新窗格落在来源旁边**：插件经桥开窗格时来源就是它自己——同一个窗格开在来源那一组，别的窗格开到来源右边
  （右边有组就进那组，没有就把来源那组对半分）；不再贴整个容器的边、不再整片重新分宽
- **预览每组一个**（按窗格算），新标签插在活动标签的右边

追法：dev 钉与 peer 下限抬到 `0.10.0`，跑 check。对本仓的实际影响：单元树里第一次点开文件，原文窗格落在
单元树旁边，不再盖住单元树。「焦点原文窗格」那套总线路由这一版照样能用，暂时不用动——spec 第四期要撤掉它、
恢复「再开一份」，那要等外壳第二期的 `kind` 与 `setPaneContent`。

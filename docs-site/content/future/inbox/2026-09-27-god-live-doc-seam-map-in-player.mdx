本站首页的接缝图 `src/components/unit-folder-seams.tsx` 是手写的一份：数据、坐标、画法、交互都在一个文件里。
同样的图现在由讲解播放器 `@godcreator/explainer-player` 0.1.1 画，god-live-doc 的站已经改用它。照旧能用，不急；要换时照下面改。

**依赖与样式**：站的 `package.json` 加 `@godcreator/explainer-player` 0.1.1；全局样式引一次
`@import '@godcreator/explainer-player/styles.css';`（接缝图的样式在里面，不用另写）。

**拆成三份文件**：

- 内容 `unit-folder-seams.data.mjs`：`import { defineSeamGraph } from '@godcreator/explainer-player/seam-graph'`，
  写模块（`id`、`name`、`pkg`、`role`、`outside`、`blurb`、`caps`）、入口、接缝（`n`、`name`、两端能力 `a` / `b`、`iface`、
  `convention`、`via: 'code' | 'disk'`、`text`）。id 重复、两端指向不存在的能力，加载时报错
- 坐标 `unit-folder-seams.layout.ts`：一张 `SeamLayout`（画布、能力方块用 `cap(x, y, w)` 建、模块框、每条接缝的 `d` 与编号圆点、
  入口箭头、模块与入口的图标），`cap` 与类型从 `@godcreator/explainer-player` 取；图标传站自己装的图标组件
- 画面 `unit-folder-seams.tsx`：`'use client'`，`<SeamDiagram graph={…} layout={…} />`

**机读规则**：`docfirst.config.mjs` 里 `UnitFolderSeams` 的规则改成
`(node, h) => seamGraphText(graph).map((text) => h.paragraph(text))`（`seamGraphText` 从 `./seam-graph` 取，按本站规则的参数名改）。

**数据形状按包的来，包不跟着扩**：

- 半调用半读盘的那种接缝（`look: 'mixed'`）拆成两条接缝，一条 `via: 'code'`、一条 `via: 'disk'`
- 每条接缝的「谁负责」（`owner`）并进 `text`，「契约」（`contract`）写进 `iface`
- 外部对象（人、命令总线、外壳……）写成 `outside: true` 的模块，只有一个能力、名字相同的在布局里 `groups` 写 `null`，不画外框

画法怎么用、几条硬性规定，看说明书 `docs-site`（`run skill.read {"name":"docs-site"}`）的「描述一个系统：先画接缝图」；
现成的例子是 god-live-doc 站的 `docs-site/src/components/seam-map/`。

# 跟上外壳窗格模型第二版

**本页回答**：外壳（`@godcreator/gwb-shell`）窗格模型第二版落地之后，本仓要改哪几处、做到哪了。

总方案住外壳那个仓（gwb-ui-plugins 站 spec 区 `pane-model-v2`），本页只接它「消费方怎么跟」表里本仓那两行：
`main`（单元）是工具窗格，不动；`viewer`（文件原文）声明 `document`，撤掉「焦点原文窗格」那套总线路由，
单击 = 预览、Ctrl+单击 = 不要预览的普通打开、Ctrl+Alt+单击 = `placement: 'side'`，恢复「再开一份」，删掉失效的
`duplicate: true`。另外文档站件那颗「启动站点」按钮开预览格要知道来源——本仓工具条按钮点击时带上树格的实例 id。
收件箱里那条「要追 shell 0.10」也在这一趟处理掉。

## 方案

**浏览器半**：`selection.ts` 整份换掉——焦点账、接力棒、总线事件 `file-selected` 全撤，换成一份纯模块
管「这一下点击开成什么」：手势 → 开法（树格不是原文格，所以单击是预览）、文件 → 内容（key 与参数）、
参数 → 文件（原文格挂上与软换时读）。原文格改成**内容住在自己的参数里**：挂上时读 `pane.params`、外壳顶掉
预览时走 `retarget`，不再听总线、不再记焦点；于是它跟着布局落盘，整页重载回到原来那个文件。

**工具条**：`fire` 的参数多一格 `from`，值是树格的 `pane.instance`；登记方的 `args` 仍然最后铺、同名盖过它。
`ToolbarButtonSpec.command` 的注释跟着写明。

**node 半**：`registerPane` 给 viewer 加 `kind: 'document'`，撤掉「duplicable 休眠」那句注释。

**版本**：命令、服务面、事件、出生证都没动；原文格之间那条总线事件只在本件自己的桶里，不是别人对着写的面；
工具条点击参数是加一格。照 gwb-release 抬补丁号。
